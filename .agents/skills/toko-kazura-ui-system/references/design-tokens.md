# Toko Kazura Red & White Design Tokens

## Color Palette

| Token | Hex | Usage |
| :--- | :--- | :--- |
| `--kz-crimson-950` | `#2A0404` | Deepest banner crack tone & dark accents |
| `--kz-crimson-900` | `#5C0808` | Banner primary dark maroon background |
| `--kz-crimson-800` | `#7A0B0B` | Primary brand header & primary buttons |
| `--kz-crimson-700` | `#991B1B` | Interactive hover & price text |
| `--kz-white` | `#FFFFFF` | Main page background & primary card surface (No pink tints) |
| `--kz-gray-50` | `#F9FAFB` | Subtle neutral box background |
| `--kz-border` | `#E5E7EB` | Default neutral card border (turns `#991B1B` on hover) |

## Component Standards

- **Root Linktree Cards (`#/`)**:
  - Only 2 primary cards on the initial view: **Joki Game** (`#/joki-game`) and **Produk Digital** (`#/produk`).
- **Sub-Menu & Pricelist Pages**:
  - Pure white background (`#FFFFFF`), `2px` solid neutral border (`#E5E7EB`), turning `#991B1B` on hover, with full-page navigation (`#/...`) and zero popups/modals.
